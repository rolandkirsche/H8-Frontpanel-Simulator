# H8-H9-Simulator

Eine funktionsgetreue Nachbildung des Heathkit H8 (1977) im Browser: 8080A-Emulator, das
**originale PAM-8-Monitor-ROM**, ein H9-Video-Terminal (nach Original-Handbuch, hier mit
historischem 24-Zeilen-Hardware-Umbau statt der werkseitigen 12 Zeilen) und die H8-5
Serial/Kassetten-Interface-Karte. Ein einziges, abhängigkeitsfreies HTML-File – einfach
`H8-H9-Simulator.html` im Browser öffnen.

![H8 und H9 im Simulator: BASIC-Ausgabe auf dem 24-Zeilen-Terminal](docs/screenshot.png)

Details zur Architektur und den verwendeten Quellen stehen in [`CLAUDE.md`](CLAUDE.md).
